## Detailed Capabilities

### 1. Keyword Research

**Research Process:**
```
Step 1: Seed Keywords
- Identify core topics
- Brainstorm related terms
- Use customer language

Step 2: Expand Keywords
- Use keyword tools
- Find related searches
- Check suggestions

Step 3: Analyze Keywords
- Search volume
- Keyword difficulty
- Search intent
- CPC (for paid insights)

Step 4: Prioritize Keywords
- Quick wins (low difficulty, decent volume)
- High value (high volume, aligned intent)
- Long-tail opportunities
- Question keywords
```


**Search Intent Types:**
```
INFORMATIONAL: User wants to learn
- "how to", "what is", "guide"
- Content: Blog posts, tutorials, guides

NAVIGATIONAL: User seeks specific site
- Brand names, specific products
- Content: Home, product, landing pages

COMMERCIAL: User researching before buying
- "best", "reviews", "vs", "top 10"
- Content: Comparison pages, reviews, lists

TRANSACTIONAL: User ready to buy
- "buy", "price", "discount", "order"
- Content: Product pages, pricing, checkout
```

### 2. On-Page Optimization

**Page Optimization Checklist:**
```markdown
## Title Tag
- [ ] 50-60 characters
- [ ] Primary keyword near beginning
- [ ] Brand name at end (if space)
- [ ] Compelling, click-worthy

## Meta Description
- [ ] 150-160 characters
- [ ] Includes primary keyword
- [ ] Clear value proposition
- [ ] Call to action

## URL Structure
- [ ] Short and descriptive
- [ ] Includes primary keyword
- [ ] Uses hyphens (not underscores)
- [ ] No unnecessary parameters

## Header Structure
- [ ] Single H1 with primary keyword
- [ ] H2s for main sections
- [ ] H3s for subsections
- [ ] Logical hierarchy

## Content Optimization
- [ ] Primary keyword in first 100 words
- [ ] Natural keyword distribution
- [ ] Related keywords and synonyms
- [ ] Sufficient content length
- [ ] Internal links to related content
- [ ] External links to authoritative sources

## Image Optimization
- [ ] Descriptive file names
- [ ] Alt text with keywords (when relevant)
- [ ] Compressed file sizes
- [ ] Responsive images

## Structured Data
- [ ] Appropriate schema type
- [ ] All required properties
- [ ] Valid JSON-LD format
```

**Meta Tag Templates:**
```
Title Tag Formula:
[Primary Keyword] - [Benefit/Modifier] | [Brand]

Examples:
"Email Marketing Software - Automate Your Campaigns | BrandName"
"Best Running Shoes 2024 - Expert Reviews & Guide | BrandName"

Meta Description Formula:
[Hook with keyword] + [Value proposition] + [Call to action]

Example:
"Discover the best email marketing software for small businesses. 
Compare features, pricing, and find the perfect tool to grow your 
audience. Start your free trial today."
```

### 4. Technical SEO

**Technical Audit Checklist:**
```markdown
## Crawlability
- [ ] Robots.txt configured correctly
- [ ] XML sitemap submitted
- [ ] No orphan pages
- [ ] Proper canonical tags
- [ ] No crawl budget waste

## Indexability
- [ ] No unintended noindex
- [ ] Proper hreflang (if multilingual)
- [ ] Pagination handled correctly
- [ ] Parameters handled

## Site Architecture
- [ ] Flat structure (3 clicks max)
- [ ] Logical URL hierarchy
- [ ] Internal linking strategy
- [ ] Breadcrumb navigation

## Performance
- [ ] Core Web Vitals passing
- [ ] Mobile-friendly
- [ ] HTTPS everywhere
- [ ] No broken links
- [ ] Optimized images

## JavaScript SEO
- [ ] Content renders without JS
- [ ] Proper SSR/SSG
- [ ] Lazy loading implemented correctly
```

**Core Web Vitals Targets:**
```
LCP (Largest Contentful Paint)
- Good: < 2.5 seconds
- Needs Improvement: 2.5 - 4 seconds
- Poor: > 4 seconds

FID (First Input Delay)
- Good: < 100 milliseconds
- Needs Improvement: 100 - 300 milliseconds
- Poor: > 300 milliseconds

CLS (Cumulative Layout Shift)
- Good: < 0.1
- Needs Improvement: 0.1 - 0.25
- Poor: > 0.25
```

## Best Practices

### Content Optimization
- Write for humans, optimize for search
- Use keywords naturally
- Provide comprehensive coverage
- Update content regularly
- Build topical authority

### Technical SEO
- Prioritize mobile experience
- Optimize for Core Web Vitals
- Fix broken links promptly
- Maintain clean URL structure
- Use schema markup

### Link Building
- Focus on quality over quantity
- Build relationships, not just links
- Create link-worthy content
- Diversify anchor text
- Monitor backlink profile
