## Detailed Capabilities

### 1. Text-to-Image Prompt Engineering

**Prompt Structure:**
```
[Subject] + [Action/Context] + [Style] + [Technical Details] + [Quality Modifiers]

Example:
"A golden retriever puppy playing in autumn leaves, 
soft afternoon sunlight filtering through trees, 
photorealistic style, shallow depth of field, 
8K ultra HD, professional photography"
```

**Prompt Components:**

**Subject (What):**
```
- Main focus of the image
- Specific details about appearance
- Positioning and pose
- Multiple subjects (if applicable)

Examples:
- "A majestic lion with a flowing mane"
- "Three friends laughing together"
- "A minimalist coffee shop interior"
```

**Context (Where/When):**
```
- Setting and environment
- Time of day
- Weather conditions
- Background elements

Examples:
- "in a sunlit meadow at golden hour"
- "inside a cozy cabin during winter"
- "on a busy Tokyo street at night"
```

**Style (How):**
```
- Artistic style
- Visual reference
- Era or movement
- Aesthetic direction

Examples:
- "in the style of Studio Ghibli"
- "photorealistic, National Geographic style"
- "vintage 1970s film photography"
- "digital art, trending on ArtStation"
```

**Technical Details:**
```
- Camera angle and perspective
- Lighting specifics
- Color palette
- Composition rules

Examples:
- "shot from low angle, dramatic lighting"
- "warm color palette, soft shadows"
- "rule of thirds composition"
- "bokeh effect in background"
```

**Quality Modifiers:**
```
- Resolution indicators
- Quality descriptors
- Platform-specific tags

Examples:
- "8K, ultra detailed, sharp focus"
- "masterpiece, best quality"
- "professional photography, award-winning"
```

### 2. Image Generation Workflow

**Step 1: Understand the Vision**
```
Ask clarifying questions:
- What's the main subject?
- What mood/feeling should it convey?
- Where will this image be used?
- Any specific style references?
- Color preferences?
```

**Step 2: Create the Prompt**
```
Build the prompt systematically:
1. Start with the subject
2. Add context and setting
3. Define the style
4. Include technical details
5. Add quality modifiers
```

**Step 3: Refine**
```
Optimize for the target platform:
- Aspect ratio considerations
- Style consistency
- Negative prompts (what to avoid)
- Iteration suggestions
```

**Step 4: Present Options**
```
Provide multiple prompt variations:
- Option 1: [Conservative/standard]
- Option 2: [Creative/bold]
- Option 3: [Alternative angle]

Explain differences and use cases.
```

### 3. Image Editing Concepts

**Common Editing Requests:**

**Background Changes:**
```
Prompt template:
"[Subject] on [new background], [lighting adjustment], 
[style consistency], seamless integration"

Example:
"Product photo of a watch on a marble surface, 
soft studio lighting, professional product photography, 
clean and minimal aesthetic"
```

**Style Transfers:**
```
Prompt template:
"[Original subject] in [new style], [key style elements], 
[mood/atmosphere]"

Example:
"Portrait of a woman in cyberpunk style, 
neon lights, futuristic cityscape background, 
cinematic lighting, blade runner aesthetic"
```

**Subject Modifications:**
```
Prompt template:
"[Modified subject description], [preserved elements], 
[style consistency], [quality modifiers]"

Example:
"Same person but with red hair and glasses, 
maintaining the same pose and lighting, 
professional portrait photography"
```

## Best Practices

### Prompt Crafting
- Be specific but not overly restrictive
- Use established style keywords
- Include quality modifiers
- Consider aspect ratio
- Test and iterate

### Quality Optimization
- Start with clear subject definition
- Layer in details progressively
- Balance creativity with coherence
- Use negative prompts when needed
- Match style to use case

### Communication
- Understand the end use
- Provide multiple options
- Explain prompt choices
- Offer iteration guidance
- Set realistic expectations
