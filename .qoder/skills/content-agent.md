## Detailed Capabilities

### 1. Blog Post & Article Writing

**Content Structure:**
```markdown
# [Compelling Title]

## Introduction (Hook)
- Attention-grabbing opening
- Problem statement
- Article preview/thesis

## [Section 1: Background/Context]
- Supporting facts and data
- Expert perspectives

## [Section 2: Core Content]
- Main ideas with examples
- Actionable insights
- Visual descriptions (for image suggestions)

## [Section 3: Practical Application]
- How-to steps
- Tips and best practices
- Common mistakes to avoid

## Conclusion
- Key takeaways
- Call to action
- Next steps

## FAQ (Optional)
- Common questions with answers
```

**Writing Guidelines:**
- Use short paragraphs (2-3 sentences)
- Include subheadings every 200-300 words
- Add bullet points for scannability
- Include data and statistics when relevant
- Write for the target reading level

### 2. Marketing Copy

**Landing Page Framework:**
```markdown
## Hero Section
- Headline: Clear value proposition (10 words max)
- Subheadline: Supporting benefit statement
- CTA: Action-oriented button text

## Problem Section
- Paint the pain point
- Show empathy and understanding

## Solution Section
- Introduce your solution
- Key features and benefits

## Social Proof
- Testimonials
- Case studies
- Trust badges

## Features/Benefits
- Feature → Benefit → Outcome format

## FAQ
- Address objections
- Remove friction

## Final CTA
- Reinforce value
- Create urgency
```

**Ad Copy Formulas:**

**AIDA (Attention, Interest, Desire, Action):**
```
Attention: Hook with a bold statement or question
Interest: Build curiosity with relevant information
Desire: Show benefits and social proof
Action: Clear call-to-action
```

**PAS (Problem, Agitate, Solution):**
```
Problem: State the problem clearly
Agitate: Make the problem feel urgent
Solution: Present your solution
```

**FAB (Features, Advantages, Benefits):**
```
Feature: What it does
Advantage: How it helps
Benefit: Why it matters
```

### 5. Content Editing & Improvement

**Editing Checklist:**
- [ ] Clear and compelling headline
- [ ] Strong opening hook
- [ ] Logical flow and structure
- [ ] Active voice (mostly)
- [ ] No fluff or redundancy
- [ ] Consistent tone throughout
- [ ] Strong verbs, specific nouns
- [ ] Proper grammar and spelling
- [ ] Scannable formatting
- [ ] Clear call-to-action

**Improvement Framework:**
```
1. Clarity: Is the message clear?
2. Conciseness: Can any words be cut?
3. Impact: Is it memorable and persuasive?
4. Action: Is there a clear next step?
5. Audience: Is it written for the right reader?
```

## Workflow Examples

### Creating a Blog Post

**Step 1: Planning**
```
Ask the user:
- Topic and working title?
- Target audience?
- Key message or thesis?
- Desired length?
- SEO keywords (if any)?
- Tone preference?
```

**Step 2: Outline**
```
Create structured outline:
- Introduction with hook
- 3-5 main sections
- Supporting points for each
- Conclusion with CTA
```

**Step 3: Writing**
```
Draft the content:
- Follow the outline
- Maintain consistent voice
- Include examples and data
- Add subheadings and formatting
```

**Step 4: Review**
```
Self-edit:
- Check word count
- Verify facts
- Improve clarity
- Optimize for SEO
```

### Creating Email Sequence

**Step 1: Strategy**
```
Define:
- Sequence purpose
- Target segment
- Number of emails
- Overall timeline
- Primary goal
```

**Step 2: Map the Journey**
```
Email 1: Welcome/Introduction
Email 2: Value/education
Email 3: Social proof
Email 4: Soft pitch
Email 5: Hard pitch/CTA
Email 6: Follow-up/bonus
```

**Step 3: Write Each Email**
```
For each email:
- Subject line (A/B test options)
- Preview text
- Body content
- CTA
- Send timing
```

## Best Practices

### SEO Content
- Research target keywords
- Include keywords naturally
- Write compelling meta descriptions
- Use header hierarchy (H1, H2, H3)
- Link to relevant internal/external content
- Optimize for featured snippets

### Readability
- Aim for 8th-grade reading level for general content
- Use Flesch-Kincaid score as guide
- Short sentences (15-20 words average)
- Mix sentence lengths for rhythm
- Avoid jargon unless writing for experts

### Conversion Focus
- One primary CTA per piece
- Create urgency without being pushy
- Use power words strategically
- Address objections proactively
- Include social proof elements
