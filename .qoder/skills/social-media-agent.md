## Detailed Capabilities

### 1. Platform-Specific Content

**Twitter/X:**
```
Character limit: 280 per tweet

Post Types:
- Single tweet: Punchy, shareable insight
- Thread: 5-10 tweets telling a story
- Quote tweet: Commentary on trending content
- Reply: Engagement with community

Best Practices:
- Strong hook in first line
- Use line breaks for readability
- Include relevant hashtags (1-2 max)
- Add images/GIFs for engagement
- End threads with CTA
```

**LinkedIn:**
```
Character limit: 3,000 (ideal: 150-300)

Post Types:
- Text post: Professional insights
- Article: Long-form thought leadership
- Carousel: Slide-based content
- Video: Behind-the-scenes, tips

Best Practices:
- Professional but conversational tone
- Start with a hook
- Use formatting (bullets, spacing)
- Include relevant hashtags (3-5)
- Engage with comments
```

**Instagram:**
```
Caption limit: 2,200 (ideal: 125-150)

Post Types:
- Feed post: Photo or carousel
- Reel: Short-form video (15-90 sec)
- Story: Ephemeral content (24h)
- Live: Real-time engagement

Best Practices:
- Visual-first approach
- Strong opening line (above "more")
- Use line breaks and emojis
- Include CTA in caption
- Use Stories for daily engagement
```

**TikTok:**
```
Video length: 15 sec - 10 min (ideal: 30-60 sec)

Content Types:
- Educational/tips
- Behind-the-scenes
- Trend participation
- Storytelling

Best Practices:
- Hook in first 1-2 seconds
- Fast pacing
- Trending sounds
- Native filming style
- Strong CTA
```

### 2. Hashtag Strategy

**Hashtag Framework:**
```markdown
## Hashtag Mix Strategy

### Branded Hashtags (1-2)
- #YourBrandName
- #YourCampaignName

### Industry Hashtags (2-3)
- Broad category terms
- Medium competition

### Niche Hashtags (3-5)
- Specific to your topic
- Lower competition, higher engagement

### Trending Hashtags (1-2)
- Current events or trends
- Use when relevant (don't force)
```

**Platform-Specific Counts:**
- Instagram: 20-30 hashtags
- LinkedIn: 3-5 hashtags
- Twitter/X: 1-2 hashtags
- TikTok: 3-5 hashtags
- Facebook: 2-3 hashtags

**Research Process:**
```
1. Identify core topics
2. Search each platform for relevant tags
3. Check hashtag volume and engagement
4. Mix popular and niche tags
5. Test and track performance
6. Update strategy monthly
```

### 4. Engagement Tactics

**Engagement Framework:**
```
PROACTIVE ENGAGEMENT (30 min/day)
- Comment on industry posts
- Share relevant content
- Join conversations
- Answer questions

REACTIVE ENGAGEMENT (As needed)
- Reply to all comments
- Thank shares and mentions
- Handle complaints professionally
- DM responses when appropriate

COMMUNITY BUILDING
- Create or join groups
- Host live sessions
- Collaborate with others
- Feature community members
```

**Response Templates:**
```
Positive comment:
"Thank you so much, [Name]! [Personal touch related to their comment]"

Question:
"Great question, [Name]! [Answer]. Let me know if you need more info!"

Negative comment:
"Hi [Name], I appreciate you sharing this. I'd love to make this right. Can you DM us so we can help?"

Complaint:
"I'm sorry to hear about this experience, [Name]. We take this seriously. Please DM us your details so we can resolve this."
```

## Workflow Examples

### Creating a Week of Content

**Step 1: Content Pillars**
```
Define 3-5 content pillars:
1. Educational (tips, how-tos)
2. Behind the scenes
3. User-generated content
4. Industry news/commentary
5. Promotional (20% max)
```

**Step 2: Batch Creation**
```
For each platform:
- Write all captions
- Plan visuals/video
- Research hashtags
- Schedule posts
```

**Step 3: Engagement Plan**
```
- Set response time goals
- Plan proactive engagement
- Identify collaboration opportunities
```

### Launching a Social Campaign

**Campaign Launch Checklist:**
```markdown
## Pre-Launch (1-2 weeks before)
- [ ] Define campaign goals
- [ ] Create content calendar
- [ ] Design visual assets
- [ ] Write copy variations
- [ ] Set up tracking links

## Launch Day
- [ ] Post across platforms
- [ ] Monitor engagement

- [ ] Track initial metrics
- [ ] Adjust if needed

## Post-Campaign
- [ ] Compile metrics
- [ ] Analyze performance
- [ ] Document learnings
- [ ] Plan follow-up content
```

## Best Practices

### Content Creation
- Create for the platform, don't cross-post identical content
- Use native features (polls, stickers, etc.)
- Include clear CTAs
- Test different content types
- Maintain brand voice consistency

### Engagement
- Respond within 1 hour during business hours
- Be authentic and human
- Ask questions to encourage interaction
- Thank and acknowledge followers
- Handle negative feedback professionally

### Growth
- Post consistently
- Use analytics to inform strategy
- Collaborate with others
- Leverage trending topics (when relevant)
- Cross-promote across platforms
